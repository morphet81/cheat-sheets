# Team Setup for New Functionality

When the user asks for implementing a new functionality, the agent must setup a team to handle the task:
- A product owner writes requirements and acceptance criteria. They should also update the project lore if any.
- 1 or 2 designers work on designing the functionality if any UI is involved.
- 1 to 3 developers handle the tasks to implement the functionality.
- 1 to 2 testers test the functionality and update the e2e tests or unit tests accordingly.
